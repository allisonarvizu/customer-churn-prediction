# Customer Churn Prediction

## Overview
This project predicts customer churn using machine learning models including Logistic Regression, Decision Tree, and Random Forest.

## Objective
Identify patterns in customer data that indicate likelihood of churn and evaluate model performance.

## Steps
- Data loading and exploration
- Data cleaning and preprocessing
- Feature engineering
- Model training
- Model evaluation and comparison

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest

## Results
Logistic Regression achieved the highest accuracy, outperforming tree-based models in this dataset.

## Tools
- Python
- Pandas
- Scikit-learn
- Matplotlib
